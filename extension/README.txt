FrontDesk Pro — Browser Extension
=====================================
Floating Shift Log, Guest Complaints & Sales Lead Capture

Installation Instructions:
1. Open Google Chrome, Brave, Microsoft Edge, or Opera.
2. In the URL address bar, navigate to:
   chrome://extensions
3. Enable "Developer mode" in the top-right corner.
4. Click "Load unpacked" in the top-left toolbar.
5. Select this unzipped folder (which contains manifest.json).
6. The FrontDesk Pro floating bubble will now appear on all open tabs (Google, OTA Portals, PMS, Booking, CRM).

Default Connected Register:
https://cashdrawermanagement.netlify.app/app

To change the connected register URL at any time:
- Click the FrontDesk Pro puzzle piece icon in the Chrome toolbar.
- Click "✏️ Change" to input your custom or local register domain.
